# Import référentiel PR

L'écran `/developpement/pr/import` importe uniquement le catalogue des références connues.

Les données de stock présentes dans un fichier source ne modifient jamais le stock physique de Toolbox. Elles restent archivées dans le lot d'import jusqu'à ce qu'un inventaire/stock certifié soit chargé par des mouvements du grand livre PR.
